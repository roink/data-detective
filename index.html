Type guide

Binary
Exactly two states, such as yes/no or present/absent.
Categorical
Labels with no meaningful ranking, such as a country or species.
Ordinal
Ordered categories whose gaps are not necessarily equal.
Numerical
Counts or measurements where arithmetic is meaningful.

Classification complete

You found the meaning behind the values.

A data type describes how a variable behaves in analysis. That determines which summaries, visualisations, and models make sense.

Labels ≠ numbersIDs and ZIP codes may contain digits, but arithmetic on them is meaningless.
Order ≠ equal distanceRatings can be ranked without assuming each step is equally large.
Context mattersThe best classification depends on what the variable represents and how it will be analysed.
